# Обновления MedQT

## Как это работает

Приложение читает файл `version.json` из репозитория и сравнивает версию с локальной.

- если версия новее и ссылка ведет на `.zip`, Windows-сборка может скачать обновление и применить его автоматически;
- если ссылка не на `.zip`, приложение просто откроет страницу скачивания.

## Формат version.json

```json
{
  "version": "2.4",
  "package_type": "zip",
  "download_url": "https://github.com/.../MedQT-2.4-win.zip",
  "notes": "Краткое описание изменений"
}
```

## Требования к zip-пакету

Внутри zip должны лежать **файлы из папки `MedQT/`**, а не сама папка `MedQT` целиком.

Правильно:

```text
MedQT.exe
data/
templates/
windows/
widgets/
_internal/
```

Неправильно:

```text
MedQT/
  MedQT.exe
  ...
```

## Безопасность

Updater не должен перезаписывать:

- `patients.db`
- любые `*.db`
- папку `backups/`
