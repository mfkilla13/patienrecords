## MedQT v2.9.3

- Добавлен отдельный `Номер мед.карты` для истории болезни: ввод при создании, редактирование в паспортной части и вывод в шапке выписки как `ВЫПИСКА №...`.
- Доработана печать: улучшено поведение первичного осмотра и дневников, добавлен режим печати выбранных записей с нового листа, исправлены мелкие дефекты `Vis`.
- Обновлены офтальмологические списки и порядок полей местного статуса.
- В автообновлении сохранены пользовательские JSON-справочники из `data/`, чтобы обновление не затирало локальные изменения.
- Подготовлена Windows-сборка со статистикой: `matplotlib` добавлен в зависимости и в конфигурацию PyInstaller / GitHub Actions.
