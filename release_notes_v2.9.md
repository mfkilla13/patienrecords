# MedQT v2.9

## Что нового

- Существенно переработана форма выписки пациента.
- Выписка теперь разделена на 6 вкладок с пошаговой навигацией кнопкой `Далее`.
- Кнопка `Сохранить выписку` показывается только на последней вкладке `Рекомендации`.
- На вкладке `Эпикриз` добавлены быстрые вставки данных:
  - жалобы из первичного осмотра
  - диагностические исследования
  - местный статус `OD` и `OS` из формы выписки
- Убран отдельный промежуточный текстовый буфер местного статуса при выписке.
- Местный статус теперь формируется напрямую из выбранных значений формы и вставляется в эпикриз в готовом виде.
- Убрано дублирование `OD/OS` в печатной форме выписки.
- Улучшена офтальмологическая часть выписки:
  - добавлены небольшие отступы между блоками `Vis`, `ВГД`, `Эластотонометрия`, `Тонография по Нестерову`
  - расширены поля для дополнительных офтальмологических показателей при выписке
- В печати записей и обычной печати выставлены поля страницы `3 мм` по умолчанию.

## Улучшения работы с историями и печатью

- Разделена логика выписки и архивирования:
  - оформление выписки не отправляет историю сразу в архив
  - перенос в архив выполняется отдельной кнопкой с подтверждением
- Перед архивированием проверяется, что выписка действительно оформлена.
- Улучшена работа с печатными записями истории болезни.
- В список печати включён `Первичный осмотр`.

## Редактирование записей

- Улучшено редактирование структурированных записей через их родные формы:
  - первичный осмотр
  - выписной эпикриз
- Данные при повторном открытии формы восстанавливаются корректнее.

## Первичный осмотр

- Добавлена поддержка даты осмотра в форме первичного осмотра.
- Состояние формы первичного осмотра сохраняется структурированно в `notes`.
- Улучшена возможность повторного открытия и редактирования первичного осмотра.

## Дневники

- Подправлен шаблон печати дневника.
- Улучшено выравнивание левого блока с жизненными показателями.
- Уточнён вывод текста лечения.

## Диагностические исследования

- В диагностические исследования добавлена форма `ЭКГ`.

## Технически

- Обновлены данные для автообновления приложения.
- Версия приложения повышена до `2.9`.
