# MedQT v2.9.1

## Что изменилось

- Исправлено редактирование первичного осмотра:
  - добавлено поле времени рядом с датой
  - при повторном открытии записи время больше не сбрасывается на `00:00`
- Выровнено время первичного осмотра в печати:
  - отдельная печать и `Печать записей` теперь показывают одно и то же время записи
- В `Печать записей` добавлен новый режим:
  - `Печатать выбранные с нового листа`
- Исправлен вывод `Vis` в дневнике:
  - убрана лишняя черта, когда для `OD/OS` выбран вариант `пусто`
- В общий список `Глазное дно` добавлен пункт:
  - `с задней стафиломой`
- Подправлены шрифты и поведение печати первичного осмотра без смены основного печатного стиля на Windows

## Для GitHub Release

- Обновите тег до `v2.9.1`
- Файл обновления должен называться `MedQT-win.zip`
